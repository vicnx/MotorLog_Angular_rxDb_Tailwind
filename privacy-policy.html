Información detallada sobre el tratamiento de datos, modelo 100% Local-First y la integración con la API de Google Drive.

Última actualización: Septiembre 2026
100% Local-First
Tus datos residen únicamente en la base de datos de tu navegador (IndexedDB). Sin servidores externos ni bases de datos remotas.
Cero Servidores y Rastreo
No compartimos ni vendemos datos a terceros. No usamos cookies de rastreo ni empleamos datos para modelos de IA o publicidad.
Control Total del Usuario

MotorLog es una herramienta web de código abierto diseñada bajo la arquitectura Local-First para la gestión personal de registros y mantenimientos de vehículos.

2 Datos Recopilados y Almacenamiento Local

Todos los datos introducidos en MotorLog pertenecen exclusivamente al usuario y se almacenan únicamente de forma local en su navegador web (mediante IndexedDB a través de RxDB):

  • Datos de Vehículos: Marca, modelo, año, kilometraje, potencia, color y notas.
  • Registros de Mantenimiento: Fechas, importes, servicios realizados, ubicaciones e imágenes de factura/registro adjuntas.
  • Perfil Local: Nombre de usuario y avatar configurado para la sesión.
Procesamiento Local Garantizado

MotorLog no envía ningún dato a servidores propios o externos. Tu información permanece estrictamente en tu propio dispositivo.

3 Integración con la API de Google Drive y Permisos Solicitados

MotorLog ofrece la posibilidad opcional y voluntaria de conectar la cuenta personal de Google Drive del usuario para realizar copias de seguridad y sincronización entre dispositivos. Esta integración solicita exclusivamente los siguientes permisos mínimos:

Permiso: drive.appdata (Carpeta privada de datos de la aplicación)

Datos a los que accede: MotorLog accede a la cuenta de Google Drive del usuario únicamente para leer, crear y actualizar el archivo de copia de seguridad propio de la aplicación (motorLog_backup.json) ubicado en la carpeta privada oculta appDataFolder. MotorLog NO tiene acceso, no lee, no modifica ni elimina ningún otro archivo, documento, foto o carpeta de tu Google Drive.

Permiso: userinfo.email

Permite obtener la dirección de correo electrónico del usuario únicamente para mostrarla en la pantalla de Ajustes de la aplicación y confirmar visualmente qué cuenta de Google se encuentra conectada.

Finalidad del Uso de los Datos de Google:

Los datos de Google se utilizan de forma exclusiva para permitir al usuario almacenar, respaldar y restaurar sus propios registros de vehículos en su cuenta privada de Google Drive.

Declaración Explícita de No Compartición con Terceros

No vendemos, alquilamos ni compartimos los datos de los usuarios de Google con terceros ni los utilizamos para publicidad, marketing o entrenamiento de modelos de inteligencia artificial (IA / Machine Learning).

Cláusula Obligatoria de Uso Limitado de Google (Limited Use Disclosure)

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google por parte de esta app se adherirán a la Política de Datos de Usuario de los Servicios de la API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

4 Seguridad y Protección de Datos

MotorLog implementa medidas estrictas para la protección de la información del usuario:

  • Comunicaciones Cifradas: Toda interacción con los servicios de Google se realiza mediante HTTPS y el protocolo oficial de autenticación OAuth 2.0 de Google.
  • Sin Almacenamiento Central: Al carecer de servidores centrales propios, no existe riesgo de filtración masiva de bases de datos remotas.
  • Tokens en Sesión: Los tokens de acceso a Google Drive se almacenan de forma volátil en la sesión del navegador y no se persisten de forma indefinida.

5 Retención y Eliminación de Datos (Control del Usuario)

El usuario mantiene el control total sobre su información y puede ejercer sus derechos de eliminación en cualquier momento:

  • Eliminación de Datos Locales: Puedes borrar todos los datos almacenados en tu navegador desde la aplicación accediendo a Ajustes > Borrar datos.
  • Eliminación de la Copia en Google Drive: Puedes borrar el archivo de copia de seguridad (motorLog_backup.json) en cualquier momento desde la propia app o eliminando los datos de la app en la configuración de almacenamiento de Google Drive.
  • Revocación de Permisos de Google: Puedes revocar el acceso concedido a MotorLog en cualquier instante visitando la página de seguridad de tu cuenta de Google: https://myaccount.google.com/permissions.
  • Exportación y Portabilidad: Puedes descargar una copia completa de tus registros en formato estándar JSON en cualquier momento desde los Ajustes.

MotorLog Privacy Policy

MotorLog is an open-source web application designed under a Local-First paradigm for personal vehicle maintenance logging and cost tracking.

2 Data Collected and Local Storage

All information entered into MotorLog belongs strictly to the user and is stored only on their local device (via browser IndexedDB powered by RxDB):

  • Vehicle Data: Make, model, year, mileage, power, color, and custom notes.
  • Maintenance Records: Dates, service costs, performed tasks, provider locations, and attached receipt images.
  • Local User Profile: Session username and selected avatar.
Local Processing Guarantee

MotorLog does not transmit user data to any external or backend server. Your data never leaves your device unless you voluntarily create a backup.

3 Google Drive API Integration & Requested Scopes

MotorLog provides an optional feature allowing users to connect their personal Google Drive account to backup and restore their maintenance records. This integration requests only the following minimal scopes:

Scope: drive.appdata (Application-specific data folder)

Accessed Data: MotorLog accesses the user's Google Drive account solely to read, create, and update the application's own backup file (motorLog_backup.json) inside the hidden private appDataFolder. MotorLog CANNOT access, view, modify, or delete any other files, folders, photos, or documents in your Google Drive.

Scope: userinfo.email

Allows retrieving the user's email address solely to display it in the app's Settings interface so the user can visually identify the connected Google account.

Purpose of Google User Data:

Google user data is used exclusively to provide personal backup and restoration functionality requested by the user.

No Third-Party Sharing Affirmation

We do not sell, rent, or share Google user data with third parties, nor do we use it for advertising, marketing, or training artificial intelligence (AI / Machine Learning) models.

Mandatory Google Limited Use Disclosure

MotorLog's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4 Data Protection and Security

MotorLog employs robust security measures to protect user information:

  • Encrypted Transport: All interactions with Google APIs use secure HTTPS communication and official Google OAuth 2.0 protocols.
  • No Central Database: Having no backend servers prevents large-scale external database breaches.
  • Session-Only Tokens: Google OAuth tokens are stored ephemerally in browser session memory and are not permanently persisted.

5 Data Retention and Deletion Disclosures

Users maintain full ownership and control over their data at all times:

  • Local Data Deletion: You can wipe all data stored in your browser by going to Settings > Clear data.
  • Google Drive Backup Deletion: You can delete your backup file (motorLog_backup.json) directly from the application or by managing connected apps in Google Drive settings.
  • Revoking Google Access: You can revoke MotorLog's access permissions at any time through Google Account Security: https://myaccount.google.com/permissions.
  • Data Portability: You can export and download a full JSON copy of your maintenance data at any time from Settings.
