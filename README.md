> **MotorLog** is a local-first web application to track and manage vehicle maintenance, inspections, and costs with complete privacy and offline support.

### ✨ [Live Demo](https://vicnx.github.io/MotorLog_Angular_rxDb_Tailwind/)

---

## Key Features 🚀

- **Local-First Privacy**: Powered by **RxDB (IndexedDB)**. Your data stays safely on your device.
- **Cloud & Local Backups**: Sync and restore backups seamlessly via **Google Drive API** or export/import local JSON files.
- **Dynamic Brand Logos**: Real-time high-resolution vehicle brand logo integration via **Logo.dev API**.
- **Maintenance Timeline**: Complete log of services, mileage, costs, locations, and date range filters.
- **Customization**: Custom vehicle colors, brand logos, custom service types, and personalized avatars.
- **Internationalization (i18n)**: Full support for English & Spanish (`es` / `en`).
- **Tactile Minimalism & Dark Mode**: Clean design system built with Tailwind CSS and PrimeNG, fully responsive for mobile and desktop.

## Getting Started 💻

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation & Usage

1. Clone the repository:
   ```sh
   git clone https://github.com/vicnx/MotorLog_Angular_rxDb_Tailwind.git
   ```

2. Navigate into the application directory and install dependencies:
   ```sh
   cd motorlog
   npm install
   ```

3. Start the local development server:
   ```sh
   npm run start
   ```
   Open your browser at `http://localhost:4200/`.

## Built With 🛠️

- **Framework**: [Angular v17](https://angular.io/) (Standalone Components)
- **Persistence**: [RxDB](https://rxdb.info/) (IndexedDB + RxJS)
- **Cloud Sync**: [Google Drive API](https://developers.google.com/drive) (Google Identity Services)
- **Brand Logos API**: [Logo.dev API](https://www.logo.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & [PrimeNG](https://primeng.org/)
- **Avatars**: [DiceBear](https://dicebear.com/)
- **Icons**: [FontAwesome](https://fontawesome.com/) & [Flag Icons](https://flagicons.lipis.dev/)
- **i18n**: [@ngx-translate](https://github.com/ngx-translate/core)
